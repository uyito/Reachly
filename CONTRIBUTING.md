# Contributing to Reachly

Open issues and pull requests in [uyito/Reachly](https://github.com/uyito/Reachly). Include a description of the problem, the change, and the checks performed. Follow the development instructions in [README.md](README.md) and preserve the AGPL license and existing author notices.

The inherited ICLA and CCLA files describe upstream Postiz's contributor agreements. They are preserved for historical context and are not a Reachly contributor requirement.
